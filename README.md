# Academic Student Management System

A production-ready Full Stack Student Management System built using React, Node.js, Express, PostgreSQL, and Prisma.

## Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS
- React Router DOM
- Axios
- React Hook Form

### Backend
- Node.js
- Express.js
- Prisma ORM
- PostgreSQL
- JWT Authentication
- bcrypt
